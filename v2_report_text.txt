[Style: Heading 1] 1. System Architecture
[Style: Normal] The PDSA-FPGA system uses Dynamic Function eXchange (DFX) to swap mining algorithm modules at runtime. The Zynq UltraScale+ PS communicates with the Static Shell via AXI-Lite through an AXI SmartConnect. The Reconfigurable Partition contains either a Bitcoin (20x SHA-256d engines) or Kaspa mining RM, swapped via DFX without affecting the static shell.
